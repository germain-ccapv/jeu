# CCAPV Breakout

Un jeu de type Breakout basé sur la carte des communes de la Communauté de communes Alpes Provence Verdon (CCAPV).

Le projet est une adaptation de **Belgium Breakout**, développé par [amcaw](https://github.com/amcaw/belgium-breakout).

## Inspiration et projet original

Ce projet s'inspire du fonctionnement et du concept de **Belgium Breakout** :

https://github.com/amcaw/belgium-breakout

Le jeu original est également accessible en ligne :

https://amcaw.github.io/belgium-breakout/

Le code de ce projet a été adapté afin de représenter le territoire de la CCAPV et ses communes.

## Modifications apportées

Les principales adaptations concernent notamment :

* le remplacement du territoire belge par le territoire de la CCAPV ;
* l'intégration des communes de la CCAPV ;
* l'adaptation de la carte et des données géographiques ;
* l'adaptation de l'interface et des textes ;
